# Reentry - Control de Flota

App web inicial para administrar renta diaria de vehículos, ingresos, gastos, deudas, conductores, documentación y reportes.

## Abrir localmente

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor local.

## Publicar demo en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. Entra a https://vercel.com y crea un proyecto nuevo.
3. Importa el repositorio.
4. Framework preset: `Other`.
5. Build command: dejar vacío.
6. Output directory: dejar vacío.
7. Deploy.

## Nota

Esta primera versión guarda los datos en el navegador del usuario. Para producción, el siguiente paso es conectar Supabase/PostgreSQL para guardar datos en la nube.
